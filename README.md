# ComfyUI Textarea Selection Cycle

ComfyUI のテキスト入力欄で、カーソル位置を含むタグと単語の選択を切り替える拡張機能です。

## 使い方

1. ComfyUI のプロンプトなど、テキスト入力欄にカーソルを置きます。
2. `Ctrl` キーを素早く2回押します（Mac では `⌘` キーを2回）。
3. カーソル位置を含むタグ全体が選択されます。もう一度同じ操作をすると、最初にカーソルがあった位置の単語が選択されます。
4. さらに操作すると、タグ全体と単語の選択が切り替わります。

タグはカンマまたは改行で区切られた範囲です。単語は空白、カンマ、改行で区切られます。タグの前後にある空白は選択範囲に含まれません。

## インストール

このフォルダーを ComfyUI の `custom_nodes` フォルダーに配置し、ComfyUI を再起動してください。

## 対応範囲

- ComfyUI のブラウザー画面にあるテキスト入力欄が対象です。
- `Ctrl` または `Meta` キーを2回押す間隔は500ミリ秒以内です。
- 単語を選択した状態から開始した場合は、その単語を含むタグ全体が選択されます。
